# Make CSV Files
This repo contains an example of a script that generates an electrode csv file for a Neuropixels probe aligned with the central column of the BBP somatosensory cortex model. 

## Instructions

### Download data
Download the data required in the [circuit_test](https://github.com/BlueBrain/BlueRecording/blob/main/examples/circuit_test/ReadMe.md) example

### Run
To run this example, first run *launch.sh* in the *../circuit_test/simulation* folder. Then, run *WriteNPCSV.sh*
